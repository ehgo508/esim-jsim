# 이심전심 공부 가이드

## 이 문서의 사용법

이 문서는 요구사항 명세(`specs/` 폴더, 요구사항 PDF)와 짝이다. 명세가 "무엇을 만들지"를 말한다면, 이 문서는 "그걸 만들려면 무엇을 알아야 하는지"를 말한다.

- 각 장은 기능 번호와 같다. 001을 만들 때는 1장을 본다.
- 정답 코드는 없다. 개념 설명, 공식 문서 링크, 구현 순서, 스스로 확인할 질문만 있다.
- 장마다 같은 순서로 되어 있다.

| 순서 | 내용 | 쓰는 법 |
|------|------|--------|
| 1. 이 기능에서 배우는 것 | 한 줄 요약 | 시작 전에 읽기 |
| 2. 알아야 할 개념 | 개념마다 짧은 설명과 "왜 필요한가" | 모르는 것만 골라 공부 |
| 3. 공부할 문서 | 공식 문서와 검색 키워드 | 개념이 막힐 때 |
| 4. 구현 순서와 힌트 | tasks.md 작업별 힌트 | 구현하면서 옆에 두기 |
| 5. 스스로 점검할 질문 | 답을 말로 설명할 수 있어야 함 | 구현 후 소리 내어 답해 보기 |
| 6. 흔한 실수 | 초보자가 자주 걸리는 곳 | 에러가 날 때 |

## 권장 진행 방식

1. 기능의 `spec.md`를 읽고, 만들 것을 자기 말로 소리 내어 설명하거나 글로 적어 본다.
2. 이 가이드의 "알아야 할 개념"에서 모르는 것을 표시하고 문서를 읽는다.
3. `tasks.md`를 위에서부터 하나씩 구현한다. 한 작업은 30분~2시간 크기다.
4. 1시간 넘게 막히면 AI에게 "정답 코드 말고 힌트만" 물어본다. 예: "Spring Security에서 특정 URL만 인증 없이 허용하려면 어떤 설정을 찾아봐야 해?"
5. 테스트가 통과하면 "스스로 점검할 질문"에 답해 본다. 답을 못 하면 코드가 돌아가도 아직 이해한 것이 아니다.
6. PR을 올려 바뀐 코드를 처음부터 다시 읽고 합친다. AI에게 코드 리뷰를 부탁해도 된다 (고쳐 달라고 하지 말고 문제점만 짚어 달라고 한다).

## 전체 학습 지도

| 장 | 기능 | 새로 배우는 핵심 | 예상 기간 (주 10시간 기준) |
|----|------|-----------------|--------------------------|
| 0 | Spring 기초 | 서버, HTTP, DI, 계층 구조, Gradle, Git | 1~2주 |
| 1 | 회원 가입과 로그인 | JPA, Validation, 예외 처리, Security, JWT | 2~3주 |
| 2 | 국가별 요금제 조회 | 연관관계, 조회 쿼리, N+1 | 1주 |
| 3 | 주문과 결제 | 외부 API, 트랜잭션, 락, 멱등성 | 2~3주 |
| 4 | eSIM 발급 | 인터페이스 설계, 트랜잭션 경계, 실패 복구 | 1~2주 |
| 5 | eSIM 설치 안내 | eSIM 표준, 단위 테스트, URL 인코딩 | 1주 |
| 6 | 내 eSIM 사용량 | 캐시, 시간 테스트, 장애 대응 | 1~2주 |
| 7 | 보안과 운영 | 의존성 관리, 비밀 관리, 다음 단계 | 수시 |

기간은 추정치다. Java 문법만 아는 상태에서 시작하면 0장과 1장이 가장 오래 걸리고, 뒤로 갈수록 빨라진다.
